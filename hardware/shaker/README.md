# 粉の振り出し容器

トレイに粉を薄く、均一に撒くための容器です。粒どうしが重なると、くっついた粒を1つの大きな粒と数えてしまうため、これで撒きます。

| ファイル | 大きさ | 印刷の向き |
|---|---|---|
| `shaker_body.stl` | 直径40 × 高さ45 mm（容量 約44 mL） | 開いた側を上（そのまま） |
| `shaker_cap.stl` | 直径44.3 × 高さ11 mm | 穴の面を下（そのまま） |

サポートは要りません。

## 使い方
1. 測りたい粉を少量（小さじの先くらい）容器に入れて、ふたをはめる
2. トレイの上 10〜15 cm くらいで、トレイ全体に広がるように左右に動かしながら振る
3. **入れた粉は最後まで全部振り出す**（途中でやめると、出やすい大きさの粒だけが撒かれて分布が偏る）
4. 粒どうしが重なっている所が多ければ、量を減らす

## 寸法の考え方
- 穴は直径 5 mm。一番大きい粒（約 3.4 mm）より大きいので、粒をふるい分けません（茶こしなど目の細かいものは、大きい粒が残って偏るので使わない）
- ふたは逆さにして振っても外れないよう、きつめ（すき間 片側 0.15 mm）。入らなければ `shaker.py` の `CAP_CLEAR` を 0.25 に、ゆるければ 0.1 にして作り直し

再生成：`pip install manifold3d trimesh` → `python shaker.py`
