# coffee_lab：挽き目・焙煎度の写真解析（PC用）

撮影ボックス（`hardware/grind_box_v0`）で撮った写真から、挽き目の粒度分布と焙煎度（粉の色）を出し、HTMLレポートにまとめます。
スマホアプリに入れる前に、PCで撮り方と解析方法を固めるためのツールです。

## 準備（最初の1回）

1. Python 3.10 以上を入れる（https://www.python.org/ 。インストール時に「Add python.exe to PATH」にチェック）
2. `setup.bat` をダブルクリック（OpenCV・NumPy・matplotlib が入ります）

## 使い方

| やること | 操作 |
|---|---|
| 大きさの較正 | 箱のアクリル板の上に定規を置いて撮った写真を `定規で較正.bat` にドラッグ → 目盛りの2点をクリック → Enter → 長さ(mm)を入力 |
| 挽き目の解析 | `挽き目を解析.bat` をダブルクリック（`grind_samples` を解析）、または写真フォルダをドラッグ |
| 焙煎度の解析 | 写真フォルダを `焙煎度を解析.bat` にドラッグ |

結果は解析したフォルダの中の `_report` にでき、ブラウザで自動的に開きます。

- `grind_report.html` / `roast_report.html`：表・グラフ・確認用画像
- `grind_particles.csv`：粒1つずつの大きさ（Excel で開けます）

コマンドで使う場合：

```
python analyze.py grind <フォルダ> [--split] [--out 出力先] [--no-open]
python analyze.py roast <フォルダ>
python analyze.py calibrate <定規の写真> [--points x1 y1 x2 y2 --mm 長さ]
```

## スマホから直接送る（Coffee Lab アプリ）

1. PC で `撮影受信サーバー.bat` をダブルクリックして、画面を開いたままにする
   （初回に Windows のファイアウォールの確認が出たら「プライベート ネットワーク」で許可）
2. スマホの Coffee Lab アプリで「撮影」を選ぶ。同じ Wi-Fi なら PC を自動で見つけます
   （見つからないときは、上の「PC 未接続」をタップして、サーバーの画面に出ているアドレスを入力）
3. 「挽き目 / 焙煎度」「フォルダ」「条件」を選んで、丸いボタンで撮る

- 写真は `grind_samples/<フォルダ>/<条件>_<番号>.jpg`（焙煎度は `roast_samples/…`）に連番で保存されます
- 届いた写真はすぐ解析され、粒の数・D50（焙煎度は L\*a\*b\*）と確認用画像がスマホに表示されます
  （確認用画像は各フォルダの `_preview`、撮影時の設定は写真と同じ名前の `.json` に残ります）
- 「取り消し」で直前の写真を `_trash` へ移します。番号は使い回しません
- 「レポート」で、その種類の全フォルダのレポートを PC のブラウザに開きます
- PC につながっていないときに撮った写真はアプリが覚えておき、つながったら「未送信 n 枚を送る」で送れます（アプリを閉じると消えます）
- **テザリングでも使えます**：撮影用スマホ（または別のスマホ）のテザリングに PC をつなげば、Wi-Fi が無い場所でも送れます。
  Windows はテザリングを「パブリック ネットワーク」として扱うので、ファイアウォールの確認で「パブリック」にもチェックを入れてください
  （最初に「プライベート」だけで許可してしまった場合は、Windows の設定 → ネットワークとインターネット → そのテザリングのネットワークで「プライベート ネットワーク」に切り替える）
- 2台目のスマホは「ライト」を選ぶと、画面全体が指定の色で光ります（明るさ最大・画面が消えない）。タップで色を変える設定が出ます

### 背景ライトとの連携（撮影のスマホからライトのスマホを操作）

ライトのスマホも同じ Wi-Fi につないで「ライト」を開いておくと、撮影画面の「背景：…」ボタンから次のことができます（PC は不要。VPN はオフ）。

- **色・明るさ・模様を変える**：白・灰・茶系などの色、方眼 5mm の模様
- **背景を変えて連続撮影**：選んだ色に順に切り替えながら同じ粉を撮る。写真は `screen_white`・`screen_brown` のような色ごとのフォルダに入るので、どの背景が測りやすいかを比べられる
- **大きさ合わせ（方眼で自動）**：ライトに実寸 5mm の方眼を出して撮り、PC が線の間隔から 1画素の大きさを求める（粉を画面に直接置く撮り方のとき。乳白アクリルを使うときは、アクリルの上に硬貨か定規を置いて合わせる）。撮った方眼の写真と結果は `grind_samples/_calibration` に残る
- 撮った写真の `.json` に、そのときのライトの色・模様も記録される

保存先やポート番号は `config.json` に次のように書くと変えられます。

```json
"server": {"port": 47130, "discovery_port": 47131, "grind_dir": "../../grind_samples", "roast_dir": "../../roast_samples"}
```

## 写真の置き方・名前の付け方

- **グループ**：ファイル名の「_番号」より前が同じものは1つの条件としてまとめます。
  `dial12_01.jpg`, `dial12_02.jpg` → `dial12`。同じ条件で2〜3枚撮ると粒の数が増えて安定します。
- **背景ごとのフォルダ**：フォルダの直下に写真が無く、中のフォルダに写真がある場合は、フォルダごとに分けて1つのレポートに並べます。
  `grind_samples/bg1_white_paper`・`bg2_screen_backlight`・`bg3_other` をそのまま比べられます。
- 名前が `_` で始まるファイル・フォルダは無視します（`_report` など）。

## 精度を上げる仕組み（2026-10-31 追加）
- **空のトレイ**：アプリの「空のトレイを撮る」で、粉を載せる前のトレイを撮ると `blank_01.jpg` として保存されます。同じフォルダでそのあと撮った写真から、空のトレイにも写っている汚れ・傷・ほこり（約1mm以下）を除きます。トレイの出し入れのずれは自動で合わせます。トレイを拭いたら撮り直してください。空の写真に暗い所が多すぎる（粉が残っている）ときは使わず、撮り直しを促します
- **皮（シルバースキン）**：白い背景のとき、薄く茶色で赤い光をよく通すものを皮として粒度から除き、数と面積の割合を別に出します（確認用画像では黄色の線）
- **くっついた粒の切り分け**：くびれのはっきりしたくっつきだけを分けます（`split_touching`）。接する面が広いものは分けられないので、粉は振り出し容器（`hardware/shaker`）で薄く撒いてください
- **大きさ**：`um_per_px_zoom1`（ズーム1倍・トレイの面での1画素の大きさ）を、写真ごとに記録されたズームで割って使います。トレイの高さや箱を変えたときだけ、トレイの上に10円玉を置いて測り直してください

## 挽き目で出る値

| 値 | 意味 |
|---|---|
| D10 / D50 / D90（体積） | 小さい方から体積を積み上げて 10/50/90% になる大きさ。D50 の下の小さい数字は 95% の幅（写真を変えたらこのくらい動く目安） |
| D50（個数） | 粒の数で数えた真ん中の大きさ。微粉が多いと体積の D50 より小さく出る |
| 細粒% / 大粒% | 400µm 未満・1400µm 超の粒が全体積に占める割合（境目は config.json で変更可） |
| 抽出可能% | 表面から 100µm までが抽出されると考えたときの、抽出に関わる体積の割合（Gagné のモデル）。細かいほど大きい |
| くっつき疑い% | 形のへこみが大きく、2粒以上がくっついていそうな粒の割合。多いときは粉を薄く散らすか `--split` |
| 下限未満 | 小さすぎて測れない粒の数（短い方が 8画素 未満）。数にだけ入れて、分布からは外しています |

粒の大きさは「同じ面積の円の直径」、体積は「長径×短径×短径の楕円体」で見積もっています。

## 焙煎度で出る値

- **L\***：明るさ。大きいほど浅煎り。**a\***：赤み、**b\***：黄み
- Agtron 値そのものではありません。同じ箱・同じ撮り方で撮った写真どうしを比べるための値です
- 写真の中央の範囲（皿を箱の中央に置く前提）を測ります。範囲は確認用画像の緑の枠
- スマホの自動補正の影響を消すには、写真の決まった位置にグレーカード（または白い紙）を入れ、`config.json` の `roast.ref_roi` にその範囲を書きます（下記）

## config.json

| キー | 意味 | 既定 |
|---|---|---|
| `um_per_px` | 1画素あたりの大きさ（µm）。較正で上書き | 27.0 |
| `grind.threshold` | 背景の明るさの何倍より暗い所を粒とみなすか | 0.60 |
| `grind.min_short_px` | 測れる最小の粒（短い方の画素数） | 8 |
| `grind.fine_um` / `boulder_um` | 細粒・大粒の境目（µm） | 400 / 1400 |
| `grind.shell_um` | 抽出される表面の厚み（µm） | 100 |
| `grind.split_touching` | くっついた粒を分けるか（`--split` と同じ） | false |
| `roast.sample_roi` | 粉として測る範囲 `[左, 上, 右, 下]`（画像の幅・高さに対する 0〜1） | 中央 `[0.35,0.38,0.65,0.62]` |
| `roast.ref_roi` | グレー基準の範囲（同じ書き方）。null なら補正なし | null |
| `roast.ref_target` | 補正後のグレー基準の明るさ（0〜255） | 200 |

## 動作確認

`python tests/make_synthetic.py <出力フォルダ>` で、大きさが分かっている粉の合成画像を作れます。
この合成画像では、体積の D50 が真値と 3% 以内（例：752µm に対して真値 731µm）で一致しました。
焙煎度は、照明の色を変えても、グレー基準ありなら L\* のずれが 0.4 以内でした。実際の写真での精度は、実物で確かめる必要があります。
